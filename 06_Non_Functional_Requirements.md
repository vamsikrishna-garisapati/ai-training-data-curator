# Non-Functional Requirements

## Performance
- Startup <2 seconds
- >20 pages/minute

## Reliability
- Retry failures
- Resume interrupted runs

## Scalability
- 100 to 100,000 pages

## Security
- HTTPS
- Robots compliance
- No credential storage

## Maintainability
- Modular architecture
- >80% unit test coverage
- Structured logging
